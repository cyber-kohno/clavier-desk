# ClavierDesk Editor

本開発のエディターです。現行の譜面モデル・キー操作を引き継ぎ、Svelte 5 + TypeScript + ViteをTauri 2で動かします。

[製品の思想](../../../docs/product/clavierdesk.md)／[設計資料](../../../docs/plan/score-domain-model/score-domain-model.md)／[移行計画](../../../docs/plan/score-domain-model/refactoring-plan.md)

## 開発

Node.js 24系、pnpm 11.25.0、Rust、WindowsのTauri開発環境（Microsoft C++ Build Tools・WebView2）が必要です。

リポジトリのcodeディレクトリで実行します。

```powershell
pnpm install --frozen-lockfile
pnpm desktop
```

依存関係のインストール後は、このアプリのディレクトリ（code/apps/editor）から通常のnpmコマンドでも起動できます。Tauriの起動前コマンドもnpmを使うため、起動時にpnpmがPATHに存在する必要はありません。

```powershell
npm run tauri dev
```

同じディレクトリでnpm run tauri build -- --no-bundleを実行すると、インストーラーを作らず実行ファイルをビルドします。依存管理とlockファイルは引き続きcodeのpnpmワークスペースに統一します。

最初の起動はRustのコンパイルに時間がかかります。Viteは127.0.0.1:1420を固定で使い、使用中なら別ポートへ自動変更せずエラーにします。

ブラウザーだけで確認する場合：

```powershell
pnpm dev
```

## 確認・ビルド

codeディレクトリで実行します。

```powershell
pnpm check
pnpm test
pnpm build
pnpm build:desktop
```

buildはフロントエンド、build:desktopはフロントエンドを含むデスクトップ実行ファイルのビルドです。インストーラー作成・配布・署名はMVPに含みません。Windowsでの出力先はapps/editor/src-tauri/target/release/clavierdesk.exeです。

## アウトラインの小節・声部操作

小節ブロックは小節番号、拍表示、声部見出し、Upper、Lowerの5行です。各段のv1〜v3に記譜ピッチの延べ数を表示します。和音・連符・タイ継続先・付属装飾音を含み、休符は数えません。空の声部は`0`、存在しない声部は`-`です。

小節で`D`を押しながら`↓`を押すと、範囲選択を解除して上段v1のインナーフォーカスに入ります。Dを離しても継続し、対象セルの背景で編集対象を示します。

| キー | 操作 |
| --- | --- |
| ↑ / ↓ | 段移動。移動先に同番号の声部がなければ末尾声部へ移動 |
| ← / → | 存在する声部間を移動。端では停止 |
| Delete | 対象声部のノートと付随情報を削除し、全小節休符にする |
| Shift + Delete | 対象声部をノートごと削除。最後の1声部は削除せず、OKのみの警告を表示 |
| A | 対象段の末尾に声部を追加してフォーカス。各段最大3声部 |
| Esc / 上段で↑ | 小節全体のフォーカスへ戻る |
| R | 対象段・声部の小節先頭へタイムラインを移し、インナーフォーカスを解除 |

追加・削除はキーリピートせず、1回のUndoで戻せます。声部削除は現在の小節だけに適用し、後続声部の番号を詰めます。成立しなくなる小節間のタイは解除し、隣接小節の音符は残します。ペダル・オッターヴァは保持します。上段v1のアンカー音符を削除すると、その音符に付いたテンポ・強弱変更も削除されます。

## 自動運指と指番号の一括削除

タイムラインで同じ段・声部の連続したノート範囲を選択し、`M` → `Fingering` → `Auto Assign…`で専用ダイアログを開きます。指定ノート列に重なる同じ手の別声部・通常タイ列を自動的に含め、全対象の未指定部分をまとめて計算・適用します。指定済みの指番号は固定します。追加されたノート数・声部数・小節範囲をダイアログで確認できます。`Calculate` → 結果確認 → `Apply`で一括反映し、1回のUndoで戻せます。処理中の中止・ダイアログを閉じる操作では譜面を変更しません。

`Fingering` → `Clear`は、自動運指と同じく、選択ノート列に重なる同じ手の全声部・通常タイ列を対象に、指番号・保持中の指替え・付属装飾音・トリルの指番号列を一括削除します。奏法自体は残ります。

通常タイの指番号は先頭の発音ノートだけに保存し、後続ノートは継承します。途中ノートからの指番号編集も列全体に反映し、自動運指の件数・一覧はタイ列を1発音として扱います。タイ解除や先頭削除で新しい発音が生じる場合は、その先頭へ元の開始指を引き継ぎます。自動運指・一括削除ともにタイ列全体を自動追加します。旧ファイルの同じ指番号の重複は読み込み時に整理し、異なる番号や途中だけにある指替えは消さずに保持します。

`W`の直接入力では、空欄（空白文字のみを含む）でEnterを押すと指番号と保持中の指替えをまとめて削除します。入力途中は譜面を変えず、Escで取り消せます。タイ途中からの操作も先頭の指番号を削除し、1回のUndoで復元できます。装飾音・トリルの指番号も空欄確定で削除できます。

初版の自動計算は通常音・和音・休符・連符・範囲内で完結する通常タイに対応します。トリル・アルペジオ・保持中の指替えを含む範囲は理由を表示して停止します。同じ手の重なる発音・保持音を候補算出から考慮し、まとめて検証します。結果は現行の手モデルで検証しますが、探索で候補を見つけられない場合もあります。詳細は[自動運指の設計と制限](../../../docs/plan/3d-motion-lab/automatic-fingering.md)を参照してください。

## ペダル・オッターヴァのカーソル

タイムラインの`P`（ペダル）・`O`（オッターヴァ）モードは通常カーソルと位置・通常音価を共有し、モードだけを切り替えます。専用モードで変更した音価も通常入力へ引き継ぎます。その位置からプレビュー再生し、再生停止やモード解除後も位置を維持します。専用モードへ入るとノート・装飾音のフォーカスと範囲選択を解除します。音高は保持しますが専用モードでは参照しません。連符途中の位置から切り替えた場合も開始位置を保持し、移動幅には連符の補正を使わず共通の通常音価（付点を含む）を使います。

## 手元プレビューの部分起動

アウトラインで`Shift + ↑ / ↓`による範囲選択を行い、`Ctrl + P`で手元プレビューを開くと、選択された小節だけを対象にします。セクションと小節の2ブロックを選択し、実質1小節の場合も部分起動になります。小節を含まない範囲ではエラーを表示します。範囲選択がない場合やタイムラインからの起動は全曲が対象です。対象範囲はダイアログのタイトルで確認できます。

対象小節の両段・全声部を含み、テンポ・強弱・ペダルなどの文脈を引き継ぎます。範囲外の無関係な音に指番号は不要ですが、範囲に入ってくるタイは先頭の発音ノートの指番号を継承します。

## MusicXMLのインポート

デスクトップ版でCtrl＋Iを押すとファイル選択ダイアログを開きます。非圧縮の`.musicxml`／`.xml`（`score-partwise`）が対象です。圧縮形式`.mxl`と`score-timewise`は未対応です。インポートした譜面は未保存の新規プロジェクトになり、Ctrl＋Sで`.clavierdesk`として保存します。現在の編集内容が未保存の場合は、置き換える前に確認します。キャンセルや読み込み失敗時は現在のプロジェクトを保持します。

- 同一パートの2段を大譜表として扱います。複数パートの場合は2段のパートを優先して1パートを選び、他のパートは省略します。大譜表を確認できない場合も警告して上下段に割り当て、存在しない段は小節休符で補います。音部記号は上段ト音・下段ヘ音に正規化します。
- 音域は88鍵のA0〜C8（MIDI 21〜108）です。範囲外・微分音・不正な音高は省略し、和音に残る音がなければ同じ長さの休符にします。音程表記を保持できない場合は同じ実音の表記に正規化します。
- 各段は最初に現れた最大3声部を保持します。音符・休符・和音、通常の連符、弱起、調号変更、最初のテンポ、完全な和音単位のタイを変換します。声部番号は小節をまたいで対応を保持します。
- `duration`・`divisions`・`backup`・`forward`から時間位置を復元します。未対応の音価・連符・重なりなどで正確に変換できない場合、その小節の該当声部を小節休符にします。時間位置自体が不正な小節は上下段を休符にし、他の小節の取り込みを続けます。省略によって後続の音を前詰めしません。
- 途中の拍子変更は小節長だけを反映します。装飾音、強弱、スラー、ペダル、オクターブ線、途中のテンポ変更などは初期版では省略します。反復は展開せず、記譜順に各小節を1回取り込みます。省略・正規化した内容は取り込み完了ダイアログに件数と対象小節の概要を表示します。

変換処理は`infra/musicxml/import-musicxml.ts`、ネイティブファイル選択は`infra/tauri/musicxml-file.ts`、読み込み制御は`service/project/musicxml-file-controller.ts`です。変換結果とコード付き警告を分けて返すため、後から項目別にチェック方針を拡張できます。

## MCPセッションの公開

デスクトップ版でCtrl＋Mを押すと公開ON/OFFを切り替えます。ヘッダーに公開状態と完全なセッションIDを表示します。[MCPサーバーのビルド・登録・利用手順](../mcp/README.md)を参照してください。チェックアウト中はUI編集をロックし、エージェントの運指編集を作業用データに蓄積します。正常終了で一括反映・ロック解除してから完了通知します。Ctrl＋Shift＋Mまたは画面の停止ボタンで強制停止すると、未反映の編集を破棄してロックを解除します。

セクション名と運指のフロート入力は、Scorehackと同様に文字列・カーソルを自前で保持します。半角英数字と一部記号の入力、左右移動、Backspace/Delete、Enter確定、Escapeキャンセルに対応します。ブラウザーのinput・IME・貼り付けは使いません。入力中はチェックアウトを拒否し、下書きを保護します。

## 構成

srcのdomain・action・state・ui・infraはプロトタイプで整理した境界を維持しています。src-tauriは最小のデスクトップ起動のみを担当し、編集ロジックはRustへ複製しません。

codeはpnpmワークスペースです。ルートのpnpm-lock.yamlと、src-tauri/Cargo.lockを管理します。npmのlockファイルやアプリ単位のpnpmワークスペースは追加しません。

## 起動と音声プレビュー

Tauri起動時は360×260のスプラッシュを表示し、ピアノSoundFontとAudioWorkletシンセの準備完了後にメイン画面へ切り替えます。SoundFontはpublic/assets/soundfonts/clavierdesk-grand-piano.sf2に配置し、Viteのアセットとして同梱します。読み込みに失敗した場合もエディターを開き、音声プレビューが利用できないことを表示します。

フォーカス中のノートのピッチが編集された場合、そのノートのピッチ（和音なら全音）をscorehackに合わせて0.5秒試聴します。カーソル移動だけでは鳴らしません。音声エンジンはinfra/audio、試聴の音量・長さ・停止規則はservice/playbackが担当します。ブラウザー起動でも音源を読み込めますが、WebAudioの制約により最初のキー操作時にAudioContextを再開します。

public/splash.htmlが起動画面、infra/tauri/desktop-startup.tsとsrc-tauri/src/startup.rsがウィンドウ切替を担当します。SoundFont読込はこの切替通知より前に行います。


装飾音の自動運指対応（2026-11-18）: 選択した主音に付属する装飾音を含め、共通の再生計画の発音順・演奏時間で一続きに計算し、同じモーション検証を行います。指定済みの装飾音の指も固定します。未指定件数・結果一覧には装飾音を含みます。MCP候補の装飾音は親のnoteIdとgraceNoteIdで識別し、主音とまとめて原子的に適用します。アルペジオ・トリル・保持中の指替えは引き続き未対応です。
